# Delivery Phases

SlotlyFlow is implemented sequentially.

## Phase 01 — Platform Foundation
Secure account, organization, membership, RBAC, audit, protected app foundation.

## Phase 02 — WhatsApp Connection
Connect and represent an organization WhatsApp account/phone number securely.

## Phase 03 — Reliable Message Pipeline
Webhook ingress, NATS, idempotent inbound/outbound processing, provider status handling.

## Phase 04 — Contacts and Conversations
Durable contact, conversation, message domain and APIs.

## Phase 05 — Realtime Team Inbox
Operational inbox, realtime events, agent replies.

## Phase 06 — Automation Engine
Versioned deterministic automation runtime and configuration.

## Phase 07 — Human Handover
Explicit automation-to-agent lifecycle.

## Phase 08 — Self-Service Onboarding
Combine the platform into a short non-technical onboarding/go-live journey.

## Phase 09 — Billing, Analytics and Platform Admin
Usage, commercial controls, operational analytics and SlotlyFlow super-admin.

## Gate rule

Do not begin the next phase until the previous phase acceptance criteria pass or an explicit approved exception is documented.
