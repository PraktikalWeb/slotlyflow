# Acceptance Criteria — Phase 09 — Billing, Analytics and Platform Admin


- [ ] Usage is metered idempotently.
- [ ] Subscription state is durable and provider-abstracted.
- [ ] Customer analytics are tenant scoped.
- [ ] Internal admin surface requires separate privileged authorization.
- [ ] Privileged actions are audited.
- [ ] No organization member gains platform-admin access by role alone.
- [ ] Payment/provider secrets are protected.
- [ ] Tests/typecheck/lint/build pass.


## Completion rule

If a mandatory checkbox is not satisfied, the phase remains incomplete unless an explicit approved exception is documented.
