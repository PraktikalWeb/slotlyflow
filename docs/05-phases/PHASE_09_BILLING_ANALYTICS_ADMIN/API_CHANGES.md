# API Changes — Phase 09 — Billing, Analytics and Platform Admin


Customer APIs:
- subscription status;
- usage summary;
- analytics summary.

Internal admin APIs:
- organization search/health;
- connection health;
- operational failures;
- audited support operations.

Admin APIs require separate platform authorization.


## Global rules

Follow `docs/02-standards/API_STANDARDS.md`.
All request/response schemas must be explicitly validated.
