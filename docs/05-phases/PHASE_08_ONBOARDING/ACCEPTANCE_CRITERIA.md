# Acceptance Criteria — Phase 08 — Self-Service Onboarding


- [ ] New user can progress from account to live configuration without developer/API knowledge.
- [ ] Onboarding is resumable.
- [ ] All readiness blockers are explained in plain language.
- [ ] Test step proves messaging/automation path before activation.
- [ ] Activation is explicit and permission checked.
- [ ] No duplicate implementation of underlying services exists.
- [ ] Tests/typecheck/lint/build pass.


## Completion rule

If a mandatory checkbox is not satisfied, the phase remains incomplete unless an explicit approved exception is documented.
