# Acceptance Criteria — Phase 05 — Realtime Team Inbox


- [ ] Authorized user sees organization conversations.
- [ ] New messages appear without manual refresh under healthy realtime connection.
- [ ] Agent can send a reply.
- [ ] Reply uses central outbound pipeline.
- [ ] Reconnect recovers missed state from durable APIs.
- [ ] Cross-tenant realtime subscription is impossible.
- [ ] Unauthorized roles/actions are blocked.
- [ ] Tests/typecheck/lint/build pass.


## Completion rule

If a mandatory checkbox is not satisfied, the phase remains incomplete unless an explicit approved exception is documented.
