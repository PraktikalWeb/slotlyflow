# Acceptance Criteria — Phase 04 — Contacts and Conversations


- [ ] Inbound message resolves/creates correct organization contact.
- [ ] Correct conversation is resolved/created.
- [ ] Message is persisted once.
- [ ] Outbound lifecycle updates same message.
- [ ] Conversation/message APIs paginate correctly.
- [ ] Unread state works.
- [ ] Cross-tenant data cannot be read or mutated.
- [ ] Required indexes exist.
- [ ] Tests/typecheck/lint/build pass.


## Completion rule

If a mandatory checkbox is not satisfied, the phase remains incomplete unless an explicit approved exception is documented.
