# Acceptance Criteria — Phase 06 — Automation Engine


- [ ] Valid deterministic flow can be created and published.
- [ ] Published version cannot be mutated.
- [ ] Incoming conversation event advances correct session.
- [ ] Engine outputs typed actions rather than calling Meta directly.
- [ ] Session survives worker restart.
- [ ] Duplicate inbound event does not double-advance session.
- [ ] All approved step types work.
- [ ] Invalid/unsafe flow definitions are rejected.
- [ ] Tenant isolation passes.
- [ ] Tests/typecheck/lint/build pass.


## Completion rule

If a mandatory checkbox is not satisfied, the phase remains incomplete unless an explicit approved exception is documented.
