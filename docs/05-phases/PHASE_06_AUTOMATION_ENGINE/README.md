# Phase 06 — Automation Engine

## Objective

Implement a deterministic, durable, versioned automation runtime independent of Meta-specific transport details.

## Dependencies

Phase 04 complete; Phase 05 may exist for visibility but engine must not depend on UI.

## Gate

This phase is complete only when every mandatory item in `ACCEPTANCE_CRITERIA.md` passes or an approved documented exception exists.
