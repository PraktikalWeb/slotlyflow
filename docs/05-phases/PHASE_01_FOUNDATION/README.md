# Phase 01 — Platform Foundation

## Objective

Establish a secure, production-grade, multi-tenant application foundation before any WhatsApp functionality is introduced.

## Dependencies

None.

## Explicitly out of scope

WhatsApp integration, NATS business workflows, contacts, conversations, inbox, automation, handover, billing, analytics, AI.

## Gate

This phase is complete only when every mandatory item in `ACCEPTANCE_CRITERIA.md` passes or an approved documented exception exists.
