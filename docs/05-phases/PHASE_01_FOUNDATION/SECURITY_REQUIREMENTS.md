# Security Requirements — Phase 01 — Platform Foundation


- Passwords use a modern memory-hard hash.
- Auth failures do not reveal account existence unnecessarily.
- Verification/reset tokens are random, short-lived, single-use, and stored hashed.
- Authentication endpoints are rate-limited.
- Sessions are revocable.
- Browser session cookies are HttpOnly and Secure in production.
- CSRF design is explicit for cookie-authenticated state changes.
- Every organization operation verifies membership and permission.
- OWNER protection prevents an organization from accidentally losing its only valid owner without an explicit supported transfer/delete flow.
- Role changes are audited.
- Cross-tenant tests are mandatory.
- No environment values or secrets are generated by Codex.


## Gate

A security requirement is not optional merely because functional tests pass.
