# Acceptance Criteria — Phase 02 — WhatsApp Connection


- [ ] Authorized organization can initiate connection.
- [ ] Valid provider callback creates organization-scoped connection records.
- [ ] Connected phone number is visible in safe product terms.
- [ ] Provider credentials are not stored/logged in plaintext.
- [ ] Unauthorized roles cannot manage connection.
- [ ] Cross-tenant access is blocked.
- [ ] Connection changes are audited.
- [ ] Provider failures produce stable safe errors.
- [ ] Tests/typecheck/lint/build pass.
- [ ] No message automation/inbox is implemented prematurely.


## Completion rule

If a mandatory checkbox is not satisfied, the phase remains incomplete unless an explicit approved exception is documented.
