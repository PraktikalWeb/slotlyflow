# Acceptance Criteria — Phase 07 — Human Handover


- [ ] Handoff follows documented state machine.
- [ ] Automation pauses when human owns conversation.
- [ ] Concurrent accept has one winner.
- [ ] Agent can reply while active.
- [ ] Completion applies explicit resume policy.
- [ ] Paused timer semantics are correct.
- [ ] Every sensitive transition is audited.
- [ ] Cross-tenant access is blocked.
- [ ] Tests/typecheck/lint/build pass.


## Completion rule

If a mandatory checkbox is not satisfied, the phase remains incomplete unless an explicit approved exception is documented.
