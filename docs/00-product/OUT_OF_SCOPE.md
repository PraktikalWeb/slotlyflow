# Global Out of Scope

Unless a later approved phase explicitly adds them, do not implement:

- Native mobile apps.
- General-purpose workflow automation.
- Omnichannel support.
- Autonomous agentic AI.
- Customer-defined code execution.
- Full CRM.
- Social media management.
- Advertising management.
- Generic integrations marketplace.
- Advanced BI/data warehouse UI.
- Multi-region active-active deployment.
- Database sharding.
- Kafka.
- Service mesh.
- Dozens of microservices.

These may be reconsidered only through an approved product/architecture decision.
