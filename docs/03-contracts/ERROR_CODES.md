# Error Codes

Initial categories:

- `VALIDATION_ERROR`
- `AUTHENTICATION_REQUIRED`
- `INVALID_CREDENTIALS`
- `EMAIL_NOT_VERIFIED`
- `ACCESS_DENIED`
- `RESOURCE_NOT_FOUND`
- `RESOURCE_CONFLICT`
- `RATE_LIMITED`
- `TENANT_CONTEXT_REQUIRED`
- `INVALID_STATE_TRANSITION`
- `WEBHOOK_SIGNATURE_INVALID`
- `DUPLICATE_EVENT`
- `PROVIDER_TEMPORARY_FAILURE`
- `PROVIDER_PERMANENT_FAILURE`
- `DEPENDENCY_UNAVAILABLE`
- `INTERNAL_ERROR`

Phase specifications may add stable codes. Do not expose raw provider secrets/errors directly to clients.
